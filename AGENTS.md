# Academic website preferences

- Website work and GitHub or other repository contributions are not talks or seminars. Never add them to `talks` or describe the contributions as presentations or speaking invitations.
- Such contributions may be proposed for `news`, but ask George for explicit approval of the specific News entry before adding it. A general request to review or update the website does not approve these entries.
- A talk or seminar entry needs evidence of an actual speaking event identifying George as a speaker, with an event name and date. Website or repository activity alone is not evidence of a speaking event.
- Follow `prompts/review-academic-updates.md` for academic update reviews. Keep `content/academic-profile.yaml` as the source of truth and regenerate academic content rather than editing generated HTML or LaTeX directly.
